# Solar Equity
### Understanding Solar Photovoltaic Adoption Across Europe

## Overview

Solar Equity is a spatial data science project investigating
the socio-economic and geographical factors associated with
solar photovoltaic adoption across European countries.

The objective is to understand differences in solar adoption
and explore implications for more equitable energy policies.

## Research Question

What socio-spatial factors influence rooftop solar adoption
across the European Union?

## Methodology

The project combines:

- Data collection and integration
- Data cleaning and preprocessing
- Exploratory data analysis
- Spatial analysis and visualization
- Multiple linear regression (OLS)

## Technologies

- GeoPandas

## Data Sources

- Eurostat
- European Commission Joint Research Centre (JRC)
- World Bank
- Our World in Data

## Key Findings

The analysis identified associations between photovoltaic
adoption and several economic, demographic, and technical
variables.

The exploratory regression model reported a test R² of
approximately 0.90.

These associations should not be interpreted as causal
relationships.
